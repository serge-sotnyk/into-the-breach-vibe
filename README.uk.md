# IRON GRID

Браузерна покрокова тактична гра про мехів, створена на честь *Into the Breach*. Командуйте трьома мехами на компактних островах розміром 8×8 клітинок, стежте за намірами атак веків і використовуйте позиції, відштовхування та місцевість, щоб зберегти цивільну енергомережу. Кампанія проходить через кілька островів і завершується фінальним боєм із двох частин.

Усю графіку (ізометричні діорами, мехів, веків, ефекти) та весь звук (ефекти й атмосферну музику) створено програмно, без зовнішніх графічних чи звукових ресурсів. Гра доступна англійською та українською.

**Грати онлайн:** https://serge-sotnyk.github.io/into-the-breach-vibe/

## Як усе почалося

В оригінальній грі *Into the Breach* мені найбільше бракувало можливості зберігати гру вручну й повертатися до цих збережень. Тож я вирішив спробувати створити власну версію за допомогою вайбкодингу — як експеримент у дусі [opus-55-effort-comparison](https://github.com/Barty-Bart/opus-55-effort-comparison).

Ось найперший промпт, з якого виріс увесь проєкт. Залишаю його в оригінальному англійському формулюванні:

> Build a complete, polished, playable browser clone of Into the Breach. Capture the experience of commanding three distinct mechs in compact turn-based battles, anticipating clearly telegraphed enemy attacks, using positioning and pushes to protect civilian buildings and the power grid, and upgrading your squad through an island campaign with a final battle. Include manual saving and loading with multiple persistent save slots, available between islands. Saved campaigns must survive browser restarts and remain loadable after defeat. Make the implementation decisions yourself. Prioritize an enjoyable game, clear tactical feedback, strong visual presentation and systems that work together. Test it yourself before finishing, and leave it running so I can play it.

## Запуск

```bash
npm install
npm run dev
```

Потім відкрийте http://127.0.0.1:5173.

Кожен пуш у `main` автоматично збирається, проходить тести й публікується на GitHub Pages через `.github/workflows/pages.yml`.

Інші скрипти:

| Скрипт | Що робить |
| --- | --- |
| `npm test` | Тести рушія, кампанії, збереження, завантаження та перекладів, зокрема повні кампанії без графічного інтерфейсу |
| `npm run typecheck` | Перевірка типів TypeScript |
| `npm run build` | Збірка для публікації в `dist/` |
| `npm run balance` | Окремий звіт про баланс: автопілот проводить десятки боїв за кожен загін на різних етапах кампанії |

Додайте `?debug` до URL, щоб увімкнути налагоджувальні клавіші в бою: `P` вмикає або вимикає автопілот, `F9` миттєво завершує поточний бій перемогою.

## Як грати

- **Хід.** Веки рухаються першими й точно показують, куди вдарять: червоні смугасті клітинки, стрілки, числа шкоди та черга атак. Потім кожен ваш мех може один раз переміститися й застосувати одну зброю або відремонтуватися. Коли ви завершите хід, веки атакують по черзі.
- **Відштовхування — головний інструмент.** Цілі атак веків залежать від положення нападника, тож відштовхування века зміщує і його атаку. Зіткнення бійців між собою або з перешкодами завдає 1 од. шкоди. Наземні веки тонуть у воді, а в провалля падає будь-хто.
- **Енергомережа.** Кожна одиниця шкоди будівлі забирає енергію мережі. Коли енергія падає до нуля, часову лінію втрачено. Захист мережі дає шанс уникнути шкоди від кожного удару.
- **Ефекти стану та місцевість.** Вогонь, дим, КИСЛОТА, лід, щити, павутиння, ліси, що спалахують, пісок, що перетворюється на дим, лід, що розколюється й стає водою, лава. Є вісім небезпек довкілля: авіапідтримка, гроза, припливна хвиля, сейсмічна активність, піщана буря, крижана буря, кислотний дощ і вулканічний дощ.
- **Передбачайте наслідки.** Наведіть вказівник на ціль, щоб побачити точний результат: шкоду, відштовхування, знищення та втрату енергії мережі. Наведіть на ворога, щоб виділити лише його атаку. `Z` скасовує переміщення, а кнопка **«Переграти хід»** дозволяє раз за бій скасувати всі дії ходу.

### Кампанія

Чотири острови — Зелені простори, Безкраї дюни, Льодовий шпиль і Жаринні заводи — мають власну місцевість, веків, небезпеки та ватажка. Захистіть три регіони, а потім утримайте штаб під натиском ватажка Вулика, щоб захистити острів. Знищення ватажка — додаткова ціль. За додаткові цілі ви отримуєте репутацію, енергію мережі, ядра реактора та нових пілотів. Після кожного острова витрачайте репутацію в крамниці; ядра реактора живлять зброю й поліпшення в ангарі. Пілоти підвищують рівень, але гинуть разом зі своїм мехом. Захистіть два острови, щоб відкрити фінальний штурм Кальдери Вулика: утримайте Край кальдери, а потім захистіть бомбу «Пролом» від Тирана Вулика.

### Збереження

- **Ручні збереження:** шість слотів, доступних на мапі світу між островами (кнопка «Зберегти гру»). Завантажити гру можна з головного меню, мапи світу та екрана поразки.
- **Надійність збережень:** дані зберігаються в `localStorage` (`irongrid.v1.slot.N`) і залишаються після перезапуску браузера. Поразка в кампанії ніколи не зачіпає ручних збережень.
- **«Продовжити»:** поточна кампанія також зберігається автоматично — між місіями та на початку кожного ходу в бою — під окремим ключем. Кнопка **«Продовжити»** в головному меню повертає до гри після закриття вкладки. Коли кампанія закінчується, автозбереження очищується.

## Мови

Під час першого запуску гра використовує мову браузера. Її можна будь-коли змінити в меню «Налаштування» або кнопками EN / УКР у головному меню. Поточний екран одразу оновиться, навіть під час бою.

Усі тексти містяться в `src/i18n/`:

- `en.ts` — вихідний словник. Тексти ігрових даних (бійців, зброї, островів…) привʼязані до їхніх ідентифікаторів.
- `uk.ts` — український переклад. Перевірка типів відхиляє пропущені, зайві та неправильно оформлені ключі, а `tests/i18n.test.ts` перевіряє параметри підстановки, розмітку й форми множини.
- `glossary.uk.md` — узгоджена українська термінологія та правила стилю.

Щоб додати мову, перекладіть `uk.ts` у новий файл, зареєструйте її в `LANGS` у `src/i18n/index.ts` та в тесті. За потреби додайте в `src/main.ts` набір символів шрифту для її писемності (Chakra Petch підтримує латиницю, Tektur додає кирилицю).

## Структура коду

- `src/game/battle/` — рушій ігрових правил. `effects.ts` обробляє шкоду, відштовхування, місцевість та ефекти стану; `attacks.ts` перетворює зброю на списки ефектів; `ai.ts` планує ходи веків, моделюючи всі варіанти; `turn.ts` керує перебігом ходу; `preview.ts` моделює результати для інтерфейсу.
- `src/game/campaign/` — острови, місії, нагороди, крамниця, ангар, пілоти та слоти збережень.
- `src/render/` — ізометричне малювання на canvas, процедурні спрайти, частинки та програвач анімацій, що відтворює записані кроки бою.
- `src/ui/` — екрани (головне меню, вибір загону, мапа світу, мапа острова, бойовий інтерфейс, крамниця, підсумки кампанії) та модальні вікна (ангар, збереження, результати, налаштування, довідка).
- `src/i18n/` — словники, правила множини та пошук назв ігрових даних; ігрова логіка передає лише ідентифікатори й ключі повідомлень.
- `src/audio/` — синтезатор WebAudio для звукових ефектів і музики.
